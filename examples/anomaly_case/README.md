# Anomaly Case – Driver Introspective Proxy Example

This example demonstrates the pipeline:

1. Load metadata and models  
2. Parse incoming packets  
3. Detect anomalies  
4. Trigger introspective risk evaluation  
5. Activate rollback / self-defense  
6. Log intrusion event  

The case simulates a corrupted sensor packet stream (lidar + wheel speed mismatch).
